## Общее описание

**Geometric Lib** — это библиотека на Python для вычисления площади и периметра
геометрических фигур: круга, квадрата, прямоугольника и треугольника.

Каждая фигура реализована в отдельном модуле и предоставляет две функции:

- `area(...)` — вычисление площади;
- `perimeter(...)` — вычисление периметра (или длины окружности для круга).

Все функции принимают числа (`int` или `float`) и возвращают число.

## Описание функций

### circle.py

**`area(r)`** — принимает радиус круга `r`, возвращает его площадь.

- Формула: `π * r²`
- Пример вызова: `area(5) -> 78.53981633974483`

**`perimeter(r)`** — принимает радиус круга `r`, возвращает длину окружности.

- Формула: `2 * π * r`
- Пример вызова: `perimeter(5) -> 31.41592653589793`

### square.py

**`area(a)`** — принимает сторону квадрата `a`, возвращает его площадь.

- Формула: `a²`
- Пример вызова: `area(5) -> 25`

**`perimeter(a)`** — принимает сторону квадрата `a`, возвращает его периметр.

- Формула: `4 * a`
- Пример вызова: `perimeter(5) -> 20`

### rectangle.py

**`area(a, b)`** — принимает стороны прямоугольника `a` и `b`, возвращает его площадь.

- Формула: `a * b`
- Пример вызова: `area(3, 4) -> 12`

**`perimeter(a, b)`** — принимает стороны прямоугольника `a` и `b`, возвращает его периметр.

- Формула: `2 * (a + b)`
- Пример вызова: `perimeter(3, 4) -> 14`

### triangle.py

**`area(a, h)`** — принимает сторону треугольника `a` и высоту `h`, проведённую к этой стороне, возвращает площадь.

- Формула: `½ * a * h`
- Пример вызова: `area(5, 12) -> 30`

**`perimeter(a, b, c)`** — принимает три стороны треугольника, возвращает его периметр.

- Формула: `a + b + c`
- Пример вызова: `perimeter(3, 4, 5) -> 12`
